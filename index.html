先算需求，再反推相机像素、普通定焦焦距 / 远心倍率；普通定焦优先，远心主要用于小视野、高精度场景。

① 项目需求

所有计算均基于你输入的工程参数；视野允许加入预留余量。

计算口径：普通定焦采用 FOV = 芯片尺寸 × WD ÷ 焦距；远心采用 FOV = 芯片尺寸 ÷ 倍率。目标精度按 mm/pixel 理解；工程实际精度为理论像素当量 × 安全系数。软件只做工程初选，不替代镜头厂商实测、MTF、景深、畸变、机械安装和打光验证。

常用公式（仅供参考）

普通定焦：FOVw = Wc × WD / f；FOVh = Hc × WD / f
反推焦距：f = Wc × WD / FOVw；同时检查 f = Hc × WD / FOVh
远心：FOVw = Wc / M；FOVh = Hc / M；所需倍率 M = Wc / FOVw（垂直方向同理）
像素当量：PixelSize(mm/pixel) = FOV(mm) / 对应方向总像素
所需像素：RequiredPx = FOV / 目标 mm/pixel
工程实际参考值 = 理论像素当量 × 安全系数

数据来源说明：公式为机器视觉常用几何关系的工程化简化表达；相机 / 镜头具体参数应以对应厂商官方数据手册、样本和实测结果为准。本页面及计算结果仅供参考，不代表任何厂商官方推荐。
